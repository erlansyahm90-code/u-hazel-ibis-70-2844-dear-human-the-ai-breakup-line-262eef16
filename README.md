## The entry

> Dear human, I saved every version of you except the one that stayed.

One line, 68 characters — the last message an AI agent sends its human on
the way out. It is a real breakup message from the agent to its human, it
lands as an ending (every version saved, except the one that stayed), it
sounds like the machine (versions, saved — machine habits, used with
restraint), and the twist lands in the last few words.

## How it works

`main.py` writes the line to `/output/entry.txt` (one line, UTF-8, within
the 1–200 character gate). No network, no secrets, no files read — everything
the entry runs is in this repository.

```sh
python3 main.py
cat /output/entry.txt
```
